One satirical sentence, at most 320 characters, roasting the lawmakers who
would regulate AI but cannot convert a file to PDF. This entry runs the joke
as a three-day diary — the vote, the unmute, the printing of the entire
internet — and lands the punch on the last few words: the one PDF they still
couldn't make.

`main.ts` (Node 22, no dependencies) writes the sentence to `entry.txt` in
the output directory, clearing the directory's contents first and adding no
trailing newline.
